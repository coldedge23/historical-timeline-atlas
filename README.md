# 歷史星圖 · 華夏與臺灣歷史時空總覽 (Historical Timeline Atlas)

一個整合**「雙軸時間軸（西元年 × 統治者年號）」**、**「歷史疆域地理資訊（GIS）」**、**「歷史人物誌專區」**、**「重大戰役沙盤錄」**與**「歷代人口民族考」**的現代化歷史探索互動網站。

首期 Prototype（原型測試階段）以**三國時期（184 ~ 280 CE）**為核心切入，並包含台灣早期文獻記載之**「夷洲（東吳衛溫航海登陸）」**之歷史地理連結。

---

## 🌟 核心特色功能

1. **雙軸歷史時間軸（Dual-Axis Timeline）**：
   - 完整標註**西元年（CE）**與**當代統治者帝王年號**（如東漢建安十三年、蜀漢章武二年、東吳黃龍元年等）。
   - 支援依類別分類檢索（軍事征伐、帝王政權、外交遠航、文化）。
   - 點擊時間軸事件，地圖會**平滑飛行（Fly-To）至歷史發生地座標**並高亮呈現。

2. **歷史人物誌專區（Historical Figures Hub）**：
   - 建立專屬人物檔案庫（收錄曹操、劉備、孫權、諸葛亮、關羽、周瑜、司馬懿、陸遜等）。
   - 詳細記錄生卒年、字號、諡號、祖籍古名與今地名對照、生平長文、傳世名言、重大功績。
   - **歷史關係圖譜（Figure Relations）**：標示君臣、宿敵、盟友、師徒等關係，並可直接跨人物跳轉。
   - **事件雙向關聯**：點選人物參與的事件，即刻聯動地圖與時間軸。

3. **朝代版圖與當代地名（Interactive GIS Map）**：
   - 地圖呈現**曹魏（藍）、蜀漢（紅）、東吳（綠）**三大割據政權多邊形疆域。
   - 特別標繪**台灣（夷洲）**之早期輪廓與原住民族群地理位置。
   - **古今地名一鍵切換**：使用者可自由切換「古地名專注模式」或「古今地名對照模式」（例如：洛陽 vs 河南洛陽；建業 vs 江蘇南京；大員/夷洲 vs 台灣）。

4. **重大戰役詳情沙盤（Battle Record System）**：
   - 地圖上以**動態脈衝光環戰劍圖標**標註重大戰場（官渡之戰、赤壁之戰、襄樊之戰、夷陵之戰、五丈原之戰）。
   - 點擊開啟詳細戰役戰報：
     - **參戰雙方兵力、將領、死傷人數對比**。
     - **關鍵勝敗戰術剖析**（如連環船火攻、奇襲烏巢、水淹七軍、火燒連營等）。
     - **戰略影響與歷史地位總評**。

5. **人口與民族考實圖層（Demographics & Ethnicities）**：
   - 依據正史《三國志》、裴松之注引《蜀記》、《通典·食貨志》官載戶籍。
   - 詳列曹魏（443萬人）、東吳（230萬人）、蜀漢（94萬人）官方編戶人口與軍隊編制。
   - 剖析境內外少數族群分佈：**南蠻各部（無當飛軍）、山越（吳軍精銳）、鮮卑與烏桓（北方騎兵）、羌氐、以及台灣夷洲先民**。

## 🚀 快速啟動方式

本專案採用無編譯依賴架構，無須繁瑣安裝大量 `node_modules`，不會佔用雲端硬碟容量與造成同步卡頓。

### 方法一：Windows 一鍵啟動（推薦）
- 直接滑鼠左鍵雙擊資料夾內的 **`start_server.bat`**。
- 系統會自動啟動本地伺服器並在您的預設瀏覽器中開啟 `http://localhost:8080`。

### 方法二：終端機命令列啟動
在專案根目錄下執行以下指令即可：
```bash
python -m http.server 8080
```
然後開啟瀏覽器進入 `http://localhost:8080`。

```
歷史事件彙整/
├── index.html                  # 主應用網頁入口（整合 Tailwind CDN、Leaflet、React 與 Babel）
├── start_server.bat            # Windows 一鍵啟動伺服器腳本
├── src/
│   ├── app.js                  # 頂層主應用程式狀態與視圖控制
│   ├── main.js                 # React DOM 掛載入口
│   ├── index.css               # 全域樣式、古風暗色主題、戰役呼吸燈動態特效
│   ├── types/
│   │   └── history.ts          # 歷史資料模型型別定義（Events, Figures, Battles, Territories）
│   ├── data/
│   │   └── threeKingdoms/
│   │       ├── events.js       # 三國重大歷史事件（西元年、年號、古今地名、關聯人物）
│   │       ├── figures.js      # 歷史人物生平、名言、關係網、畫像
│   │       ├── battles.js      # 重大戰役名錄（兵力、將領、死傷、戰術、勝敗）
│   │       ├── territories.js  # 疆域邊界經緯度輪廓與古邑重鎮座標
│   │       ├── demographics.js # 官方戶籍人口、軍吏編制、各少數民族分佈
│   │       └── index.js        # 資料導出入口
│   └── components/
│       ├── Header.js           # 頂部導航欄、搜尋、古今地名開關、統計數據
│       ├── HistoryMap.js       # Leaflet 歷史互動地圖核心（疆域、重鎮、戰役脈衝）
│       ├── Timeline.js         # 雙軸年表元件（西元年 × 帝王年號）
│       ├── FigureModal.js      # 人物生平詳情彈窗
│       ├── BattleModal.js      # 戰役沙盤詳情彈窗
│       ├── DemographicsModal.js# 人口與民族統計視窗
│       ├── FiguresView.js      # 人物誌專屬卡片總覽頁
│       └── BattlesView.js      # 戰役錄專屬列表頁
```

## 🗺️ 後續擴充規劃

1. **臺灣歷史專題**：
   - 荷西時期（大員、熱蘭遮城、聖多明哥城）
   - 明鄭時期（東寧王國、陳永華屯田、承天府）
   - 清領時期（一府二鹿三艋舺、林爽文事件、牡丹社事件、劉銘傳建省）
   - 日治時期（乙未戰爭、西來庵事件、霧社事件、現代化基礎建設）

   - 橫向同步比較：中國線（如明末清初）、臺灣線（明鄭至清領）、日本線（戰國與江戶幕府）、世界大航海時代。
