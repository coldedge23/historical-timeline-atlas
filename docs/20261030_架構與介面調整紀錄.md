# 歷史星圖架構與介面調整紀錄

日期：2026-10-30。範圍：使用者確認正確性修正、架構整理、桌面／手機 UI 重整；六維能力保留，預設收合並標示娛樂用途。

## 完成項目

- 人物分類明確以目前時期為準，移除跨文明錯用陣營名稱的備援。
- 未知兵力不補值；保守解析可比較數字，模糊值不畫比例，已知值使用原始比例。
- 六維評分預設收合，說明娛樂用途與算法；推估關係標示系統推薦、非史實。
- 生卒不補60年；不依姓名出現順序虛構攻守指揮官。
- 共用原生 Dialog：Esc、背景阻隔、焦點管理、有名稱的關閉按鈕；核心卡片與事件支援鍵盤操作。
- 全域搜尋納入華夏、臺灣、日本；本頁篩選與全域搜尋分開。
- 修復文明、紀元、人物、戰役及事件網址還原，支援返回／前進。
- 本地依賴與 lockfile，移除線上 Tailwind；CSS 預編譯，JS/CSS 雜湊、12個JS分包，地圖與列表按需載入。
- dist 成為完整可部署目錄；預覽僅綁本機，限制發布目錄路徑；README及bat一致。
- 導覽改兩層、人物進階篩選收合、內文閱讀字級提高、地圖標題及標籤收斂。
- 手機改年表／地圖切換，減少兩個固定高度窗堆疊；加入焦點樣式及減少動態效果支援。
- 新增 DESIGN.md 及原始歷史資料驗證程式。
