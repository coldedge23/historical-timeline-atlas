## 二、首次載入（A）量測

### 2.1 量法

- 在瀏覽器以 iframe 開啟各情境網址（電腦寬 1,280 px、手機寬 375 px 各一次），等網路請求停止 1.5 秒後，記錄實際請求的所有 JS、CSS、總目錄與資料包。
- 本機預覽伺服器不壓縮，因此以瀏覽器記錄的檔案清單，用 `verify` 相同的 `zlib.gzipSync` 計算壓縮後大小。
- 圖片與 `index.html` 不計入（3.9 的定義）。
- 電腦與手機寬度請求的檔案完全相同。

### 2.3 上限 800 KB 的理由

- A ≈ 共用 124.5＋最大資料包＋該頁最大分包。三國資料包若長到 B 上限 600 KB，A 約 767 KB，仍在 800 KB 內，A 與 B 不互相衝突。
- 目前使用 77.2%，餘裕與其他上限相近（B 75.2%、D 72.9%）。
