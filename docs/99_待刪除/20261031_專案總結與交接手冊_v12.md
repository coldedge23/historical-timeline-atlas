## 五、新電腦設定與日常流程

完整步驟見 `README.md`「多電腦工作指南」。摘要：

```powershell
git clone https://github.com/coldedge23/historical-timeline-atlas.git C:\dev\historical-timeline-atlas
cd C:\dev\historical-timeline-atlas
npm ci
npm run build
npm test
```

| 時機 | 指令 |
|---|---|
| 開始前 | `git pull` |
| 改完後 | `npm run build`、`npm test`、`npm run verify`、`node scripts/validate_history_data.mjs --effective`、`npm run validate:data`（現況 174 項既有失敗，比對清單即可） |
| 確認後 | `git add -A`、`git commit -m "說明"`、`git push` |
| 本機預覽 | `npm run preview`，開 http://127.0.0.1:8080/ |

注意：
- 第一次 push 時用 **`coldedge23`** 帳號登入；其他帳號會沒有權限，GitHub 設定頁顯示 404。
- 不要在雲端硬碟的資料夾執行 `git` 或 `npm ci`，會留下 `.git/index.lock` 並損壞 `node_modules`。
- 換 AI 工具前先 commit。
