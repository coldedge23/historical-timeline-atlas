## 修改機制

- `src/data/linkCorrections.js`：42組人物別名，修復81項引用，包含宋遼fig_前綴、三國呂／lu／lv等已有明確文本證據的差異。

- `historyLinkGraph.js`：本期ID優先、保留跨期有效引用、去重、隔離缺對象或參與疑義。
- `linkedHistoryCatalog.js`：先修原始引用，再正規化，最後重驗有效圖譜，避免先前失效ID污染推薦。
- `figureLinks.js`：卡片排序／計數與詳情使用同一份有效事件及關係解析；關係網計數反映實際顯示的去重節點（含反向關係，最多8個）。
- 跨期導航：事件可開啟其他時期的人物，人物關聯事件可切換目標文明／時期；原事件已明列人物的跨期反向導航另外標記 `derivedEventLinks`，不算作別名修復。
