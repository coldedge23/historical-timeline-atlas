## 三、方法

### 1. 候選篇目

| 來源 | 適用 | 切分方式 | 連結 |
|---|---|---|---|
| 《資治通鑑》卷001–294 | 前 403 年～959 年 | 依「干支，西元（前）X年」標記切成年段，共 1,396 段 | 年段標題可解析時連到錨點，否則連到該卷頁面 |
| 《春秋左氏傳》 | 前 722 年～前 468 年 | 依魯公頁面的 `{{YL\|元年\|前722年}}` 切成年段 | 連到該年錨點 |
| 正史列傳 | 所有時期 | 沿用關聯人物在 `sourceReferences.js`／`sourceReviews.js` 已有的出處網址，依錨點找到該人物的段落 | 與人物出處相同 |
| 民國原始文件 | 民國 | 逐筆在維基文庫找原文提到事件名、日期或簽署人的文件 | 頁面 |

年段只比對與本筆同一西元年的段落；列傳只比對本筆關聯人物（含說明文字中提到、且名稱在資料集中唯一的人物）的段落。

### 2. 關鍵字

| 來源 | 例 |
|---|---|
| 事件或戰役名稱去掉「之戰」「之役」「事變」等詞尾後的片段 | 「長平之戰」→「長平」 |
| 標籤（tags） | |
| 古地名（地點欄位） | |
| 說明中以《》「」『』引用的詞句 | 拆成片段時每段至少 3 字 |

不採用的關鍵字：
- 人物姓名（含去掉字號的名稱，如「王羲之 (逸少)」→「王羲之」），避免列傳只因寫到本人就命中。
- 只有干支的詞、以「今」開頭的現代地名。
- 一般性詞彙（都城、州郡、國號、朝代名、「改革」「北伐」等），共約 170 個，任何篇目都不計。
- 都城與封號類（臨淄、邯鄲、大梁、壽春、彭城、平陽、開封府、盛京、武安君、信陵君等 40 個）：只在同年的通鑑、左傳年段中才計，在列傳中不計，因為列傳常提到都城但不一定是這件事。

### 3. 選用順序

每筆最多 3 個出處，依序取：通鑑同年段 → 左傳同年段 → 列傳。同一網址不重複。

2. 通鑑卷153 解析不出年段，未使用。
3. 通鑑 1,396 段中 541 段的標題含模板，畫面上的錨點與原始碼不同，連結只到該卷頁面，需自行往下找年份。

5. 關鍵字命中不等於內容相符：同名地點、不同年份的同一地名仍可能誤中。已人工檢視三批命中結果並排除第三節 4. 所列者，其餘未逐句核對。
