# 年代與來源分流紀錄（2026-10-30）

## 本輪結果

原始174項生卒外警告逐項分類：162項年代不相容仍待核對、8項多年度部分重疊、4項有直接原文的背景／死後影響。新生卒解析器沒有把原174項數值「修好」：此批解析新舊值相同。8項差異來自對事件期間的判讀，不能當成查證了人物參與。

實際畫面經正規化還會補入人物姓名關聯，與原始資料不同。對這一層逐項判讀的原221項為194項待確認、17項有文字依據的背景／影響、10項部分重疊。全體runtime另外有30項部分重疊（含原先未列警告者）。

- 新增共用年代解析：BCE／CE、負年份、明確民國年、未知、約年、事件起訖期間。不將帝王年號數字當成西元年，不猜補缺失生卒。
- 17條owner-specific背景判定附本地文字證據；原始人物／事件ID全部保留，不因年代外就刪除關聯。
- 人物詳情及事件卡分開顯示「背景與年代待考」，不將此類連結當作親身參與。卡片數量與詳情使用相同分流，背景筆數另列。
- 多年度部分重疊列為info而非單點年代錯誤；尚待核對的194項仍列警告。
- 原本97項別名修復及110項待確認引用保持不變。

## 來源盤點與限定核對

1862筆原始人物、事件、戰役資料都缺少明確來源欄位。442筆敘事提到《書名》，有些是人物著作或敘事，不能自動搬成引用；可直接承接的其他來源欄位為0。

本輪僅新增3筆有URL與限定claimScope的外部核對記錄：

- 張飛：核對《三國志》卷三十六張飛傳章武元年及伐吳前遇害段，不核定出生年與完整傳記。https://zh.wikisource.org/zh-hant/三國志/卷36#張飛
- 郭嘉：核對《三國志》卷十四柳城回師後病逝、曹操征荊州還巴丘遇疫後追悼的記載；不是郭嘉親自參戰證據。https://zh.wikisource.org/zh-hant/三國志/卷14#郭嘉
- 司馬懿：核對《晉書》卷一嘉平三年段的死亡記載，不把後來滅蜀／滅吳的家族背景當成親自出征。https://zh.wikisource.org/zh-hant/晉書/卷001#嘉平

全部使用2026-10-30實際讀取的原典轉錄。記錄的是特定段落與特定主張的核對，不代表該頁轉錄無誤、整份傳記已查證或圖像已獲授權；仍有1859筆沒有來源，人物關係也尚未逐筆核對。

新來源分類分為「尚未提供來源」「來源註記待補」「有參考線索，尚未核對」「有外部核對紀錄（限列明範圍）」。有URL或書名不能自動得到已核對標記。人口資料原先無具體來源仍預設寫正史的情形，已改成來源待核對。
